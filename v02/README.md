- 누르는 자리: 노트 길 아래 ~ 화면 끝 왼쪽 반·오른쪽 반. 일시정지 = 세 박 되감고 3·2·1. 전화·알람으로 소리가 끊기면 저절로 일시정지.
- 설정: 판정 3단 · 글자 소리 표시 · 뜻 · **맞히면 글자 목소리(켬/끔)** · 소리 줄 흐리게 · 치는 소리 크기 · 진동 · 움직임 줄이기 · 소리 지연 보정 · 화면 지연 보정. 설정·결과 화면 아래 크레딧 **「VOICEVOX:雨晴はう」**.

## 리듬·판정 (2차 검토 반영)
