## 만든 방법
1. **떼창 음높이 재기**: 스템 zip에서 Vocals·Backing Vocals wav만 프로젝트 밖 임시 폴더에 풀어(원곡과 어긋남 0ms, 원본은 읽기만, 끝나고 지움) 노트 자리 받는 떼창·외침을 YIN(5ms)으로 잼. 의심 자리(옥타브 오류·유성 적음)는 20ms 곡선 + 배음 합(SHS)으로 다시 봄. 노래가 미끄러지는 곳은 목소리 길이 안에서 머무는 끝음. 곡 조율은 A440과 거의 같음(C4 60.0~60.3, A4 69.05).
2. **합성**: 말하기 모델(audio_query)은 한 글자만 넣으면 숨소리처럼 금방 사그라들어 버림 → **노래 디코더(frame_synthesis)에 프레임을 직접 짜서** 넣음. 노래 지도 모델은 안 씀.
   - f0 = 목표음 그대로(쉼·자음 포함). 400ms 넘는 길게는 250ms부터 5.5Hz ±12센트 떨림. **떼창이 길게 미끄러지는 길게 2개는 떼창 곡선을 따라감**: `ko_40-3h`(こう, G4 170ms → 330ms E4 → 420~560ms E♭4 → 700ms C4), `i_58-1h`(いーー, C5 → 170~250ms D5 꾸밈 → C5).
   - 크기 = 3프레임 오름 → 꼭대기 0.058 → 몸통 0.046, 끝 4프레임 내림.
   - 자음: k 2프레임(21ms) · s 4프레임(43ms, 크기 0.012) · sh 5프레임(53ms, 0.012). 지도 모델은 s 8~9·sh 10프레임을 박 앞에 두지만, 우리는 누르는 순간 시작하므로 짧게 → 숨소리가 바로 나고 모음은 k 9~31ms·s/sh 32~55ms 뒤에 옴.
   - いい는 둘째 い 앞에서 크기를 살짝 낮춰 끊음.
3. **다듬기**: 꼭대기 대비 −30dB(s·sh는 −36dB, 숨소리 살림) 첫 표본의 1ms 앞에서 시작. 톡 220ms(8분 245ms보다 조금 짧게), いい 425ms, 길게 = 노트 길이(490~1,970ms). 앞 1.5ms·끝 30ms(길게 40ms) 코사인 페이드. 몸통 RMS −18dBFS(꼭대기 −1dBFS 아래).
4. **크기**: 노트 자리부터 목소리 길이만큼 원곡 wav와 비교(50ms 창 최대). 기준 = 곡 대비 RMS −12dB · 꼭대기 −6dB 이하 · 1~4kHz −10dB 이하 중 가장 엄한 값, `audio.js`와 같은 거르개(150Hz 고역 통과 + 2.5kHz −6dB Q 0.7)를 건 상태.
- 도구: `tools/voice_synth_ch1.ps1`(만들기, 엔진 켠 뒤, 목록 `$LIST`) · `tools/voice_measure_resp.ps1`(첫 판 떼창 음높이, 옛 채보 형식) · `tools/voice_measure_mix.ps1`(곡 대비 크기, `-VoiceJson`으로 이 voice.json) · `tools/voice_pitch_lib.ps1`(wav 읽기·YIN).
