## 만든 방법
1. **떼창 음높이 재기**: 스템 zip에서 Vocals·Backing Vocals wav만 프로젝트 밖 임시 폴더에 풀어(원곡과 어긋남 0ms 확인, 원본은 읽기만) 노트 자리 받는 떼창을 YIN(5ms 간격)으로 잼. 의심 자리(옥타브 오류·유성 적음)는 20ms 곡선 + 배음 합(SHS)으로 다시 봄. 노래가 미끄러지는 곳(10-4·20-4 내림, 24-1 올림)은 목소리 길이 안에서 머무는 끝음. 곡 조율은 A440과 거의 같음(C4 60.0~60.3, A4 69.05).
2. **합성**: 말하기 모델(audio_query)은 한 글자만 넣으면 숨소리처럼 금방 사그라들어(몸통 −37~−42dB, 음높이 못 잼) 버림. → **노래 디코더(frame_synthesis)에 프레임을 직접 짜서** 넣음.
   - f0 = 목표음 그대로(쉼·자음 포함). 400ms 넘는 길게만 250ms부터 5.5Hz ±12센트 떨림.
   - 크기 = 3프레임 오름 → 꼭대기 0.058 → 몸통 0.046으로 천천히, 끝 4프레임 내림(지도 모델 출력 범위에 맞춘 값).
   - 자음 k 2프레임(21ms, 지도 모델과 같음) → 모음이 늦게 오지 않게. いい는 둘째 い 앞에서 크기를 살짝 낮춰 끊음.
3. **다듬기**: 꼭대기 −30dB 첫 표본의 1ms 앞에서 시작. 톡 220ms(8분 245ms보다 조금 짧게 → 8분 연타에도 안 겹침), いい 425ms, 길게 = 노트 길이(490·488·983ms). 앞 1.5ms·끝 30ms(길게 40ms) 코사인 페이드. 몸통 RMS −18dBFS로 맞춤(꼭대기 −1dBFS 아래).
4. **확인**: 프로젝트에 옮긴 파일을 다시 재서 아래 표. 저장한 도구로 한 번 더 돌려 같은 값 확인.
- 도구: `tools/voice_synth_ch1.ps1`(만들기, 엔진 켠 뒤) · `tools/voice_measure_resp.ps1`(떼창 음높이) · `tools/voice_measure_mix.ps1`(곡 대비 크기) · `tools/voice_pitch_lib.ps1`(wav 읽기·YIN). 판 3·4는 `voice_synth_ch1.ps1`의 `$LIST`에 한 줄씩 더함.

## 크기 · 거르개 (섞기는 게임 코드가 함)
- 기준: 곡 대비 **RMS −12dB**(소리 검토 I2) · **꼭대기 −6dB 이하** · **1~4kHz −10dB 이하** 중 가장 엄한 값. 곡 크기·필터는 그대로(덕킹 금지). 곡 쪽은 노트 자리부터 목소리 길이만큼 원곡 wav에서 잼(50ms 창 최대).
- **거르개 제안**: 고역 통과 150Hz(Web Audio Q = −3.01, 버터워스) + **피크 −6dB @2.5kHz, Q 0.7**. 고역 셸프(−6dB @2kHz)와 1~4kHz 효과는 비슷하나 전체 손실이 적고(0.2~1.5dB) 5kHz 위 자음(k 파열)을 살림.
- 결과(거르개 건 상태, 노트별 이득 −18~−9.5dB, `voice.json notes[].gainDb`): 곡 대비 RMS −15.6~−12.0dB, 꼭대기 −18.8~−11.3dB, 1~4kHz −27.6~−10.2dB → 30개 모두 기준 안.
- 20-1 か만 1~4kHz 기준에 걸려 이득 −15dB(그 자리 떼창이 약함, 곡 1~4kHz −30.6dBFS).
- 노트를 모를 때 고정 이득 **−12dB**(모든 노트 곡 대비 −6dB 안, 단 조용한 자리는 −6.5dB까지 커짐).
- 길게를 일찍 떼면 그 자리에서 30ms 페이드로 끊음. 판정이 MISS면 안 냄(맞힘·놓침이 소리로 갈림).

## 남은 문제
1. **귀 확인 필요**(사용자 폰, 스피커·이어폰): 떼창과 섞여 '맞혔다'가 들리는지, 기계음 티, か행 자음이 또렷한지, いい가 두 글자로 들리는지.
2. **추정 음 4곳**: 10-3.5 え(C4)·11-4 い(G4, 떼창은 C4→A4로 길게 올림)·12-4 え(Eb4)·22-4 き(Eb4) — 유성 구간이 짧아 배음 합으로 정함. Eb4는 곡 조(C장조) 밖이지만 떼창이 그 높이(D4+60~80센트)로 부름. 귀로 어긋나면 D4로 바꿔 다시 만듦.
3. 채보가 바뀌면(21:4 길게 → 톡) `ko_Eb4.wav`(노트 '21-4')를 씀. 길게 판은 `ko_21-4h.wav`(판 3).
4. 판 3·4(さ행·낱말) 노트 목소리는 아직 없음 → 채보가 나오면 같은 도구로 만듦.
5. 출시판 = 원어민 녹음(계획 그대로). 그때까지 크레딧 「VOICEVOX:雨晴はう」를 정보 화면에 넣어야 시험판 공개 가능.
