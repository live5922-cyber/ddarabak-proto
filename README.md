# 따라박 HTML 프로토타입 v0.1 (2026-10-18)
- 사용자 판정(10-18): "일단은 이 게임을 html 버전으로 프로토타입으로 만드는게 우선이야."
- 범위: 1챕터 판 1(あ행 あいうえお). 곡 16마디 32초, 노트 13개(왼쪽 버튼만). 기준 문서 `docs/따라박_기획안_v0.5.html` 4~7절.
- 바깥 라이브러리 없음. 순수 JS 모듈 + Canvas 2D + Web Audio. 글꼴만 웹 글꼴(Pretendard·M PLUS Rounded 1c, 못 읽으면 시스템 글꼴).

## 여는 법
1. 로컬 서버: `powershell -ExecutionPolicy Bypass -File tools\serve.ps1 -Port 8899`
2. 브라우저: `http://localhost:8899/prototype/v0.1/`
- 파일을 두 번 눌러 열면(`file://`) 안 열림. 모듈·자료 파일을 서버로 읽어야 함.
- 폰에서 열려면 인터넷 주소가 필요함. 지금 서버는 이 컴퓨터 안(localhost)에서만 열림. 방법은 게시(GitHub Pages 등, 사용자 허락 뒤 · 새 게임을 올릴 저장소 이름부터 정함). HTTPS 주소면 폰 소리·진동이 그대로 됨.

## 조작
- 화면 아래 왼쪽 반 = 왼쪽 원 버튼(글자 노트), 오른쪽 반 = 오른쪽 원 버튼(박 노트, 판 1에는 없음).
- 컴퓨터 키: F·D·스페이스·← = 왼쪽, J·K·→ = 오른쪽, Esc·P = 일시정지.
- 흐름: 시작 → (처음 한 번) 지연 보정 '박에 맞춰 8번 치기' → 연주 → 결과 → 다시 하기. 일시정지(곡 멈춤·이어하기), 설정.

## 주소 옵션 (시험용)
| 옵션 | 하는 일 |
|---|---|
| `?autoplay=1` | 노트 시각(+ 지연 보정)에 진짜 pointerdown 이벤트를 자동으로 보냄. 지연 보정 화면 건너뜀 |
| `&lag=70` | 자동 누름을 일부러 70ms 늦게(음수면 일찍). 판정 경계 시험 |
| `?debug=1` | 왼쪽 위에 곡 시각·fps·보정값·출력 지연 |
| `?probe=1` | 프레임마다 노트 x·고리 반지름을 `window.__ttb.Rn.getProbe()`에 기록 |
| `?chart=ch1_pan1` | 다른 자료 파일(`data/<이름>.json`) |
- 콘솔 손잡이: `window.__ttb.S`(상태·판정 기록), `window.__ttb.freezeAt = 21.55`(그 곡 시각에서 화면 멈춤) → `window.__ttb.resume()`.

## 자료 형식 (`data/ch1_pan1.json`)
| 칸 | 뜻 |
|---|---|
| `song` | `kind`(synth = 코드 임시 반주 / file = 곡 파일), `file`, `combo_layer_file`, `offset`(곡 파일에서 1마디 1박이 시작하는 초), `bpm`, `beatsPerBar`, `bars`, `endBar`(이 마디 1박에 끝), `tail` |
| `chords` | 마디별 화음(꼬리 반짝·바닥 울림 음을 고름) |
| `calls` | 아저씨 부름: `bar`, `syl`[{`beat`, `k`}], `word`(낱말이면 {kana, ko, ro, mean}), `end`(knock = 딱따기 두 번 / seino) |
| `notes` | 노트: `bar`, `beat`(1·1.5·2 …), `k`, `btn`(L/R), `call`·`syl`(어느 부름의 몇째 글자에서 내려오는지) |
| `listen` | 듣기만 하는 줄(노트 없음): 아는 글자만 또렷, 나머지 물결 무늬. `sing`은 임시 목소리 가락 |
| `lyrics` | 하나의 한국어 줄(화면 가사) |
| `hits` | 장면 닫는 한 방 등 소리만 있는 사건 |
- 시각 = ((마디 − 1) × 4 + (박 − 1)) × 60 / bpm. 노트는 곡에서 실제로 소리 나는 자리(떼창 글자)에만(원칙 1).

## 곡 바꿔 끼우는 법 (Suno 곡이 오면)
1. 곡을 `prototype/v0.1/assets/music/ch1_winter_full.mp3`에 넣음(폴더는 그때 만듦).
2. `data/ch1_pan1.json`의 `song.kind`를 `"file"`로, `offset`을 곡에서 1마디 1박이 시작하는 초로(`tools/tempo_fit.ps1`·`onsets.ps1`로 잼), `bpm`을 실제 빠르기로.
3. 노트 자리를 실제 떼창 소리 자리로 고침(`tools/vowel_grid.ps1`·`onsets.ps1`). 곡 크기는 코드가 재기만 하고 바꾸지 않음. 효과음 크기는 곡 꼭대기에 맞춰 자동으로 정해짐.
4. 콤보 반주 층(콤보 10에 여는 손뼉 층)은 스템으로 만든 파일을 `combo_layer_file`에 적었을 때만 씀. 곡 파일을 쓰면 합성 손뼉 층은 끔.
- 곡 파일을 못 읽으면 임시 반주로 돎(콘솔에 알림).

## 지킨 규칙 (기획안 v0.5 · CLAUDE.md 원칙)
- 시계 하나: 곡·효과음·꼬리 모두 같은 AudioContext 시간표. 화면·판정은 '들리는 시각'(getOutputTimestamp, 없으면 currentTime − 출력 지연). requestAnimationFrame은 그리기만.
- 누르는 즉시(pointerdown) 몸통 + 어택 + 글자 목소리를 `start(0)`. 꼬리는 판정 뒤 '노트 + 1/16박(밑음)·1/8박(5도)'. 누른 뒤 40ms 안 꼬리는 뺌.
- 곡 길 크기·필터 변화 0(덕킹 없음). 효과음 묶음 꼭대기: 보통 곡 대비 −10dB, '크게'도 −6dB(미리 그려 재고 자동으로 줄임). MISS 개그 −14dB, 다음 박에.
- 화면: 아이폰 12(390×844) 좌표를 화면에 맞춰 늘림, 배경은 화면 끝까지, safe-area 지킴, DPR 상한 2. 노트 길 1박 144px, 말풍선 지름 64, 원 버튼 지름 120·중심 x 104/286, 고리 지름 192 → 노트 시각에 버튼 가장자리.
- 판정 연출: PERFECT 종이 띠 8장 + 무대만 2~4프레임 멈춤(마디 첫 박이면 가로 4px 흔들림) + 하나 '사진 찍기', GREAT 하늘 종이 고리 + 인형 4px 튐, GOOD 민트 조각 3개, MISS 말풍선 뒤집혀 떨어짐 + 회청 딱지 −8° + 인형 두 색 테두리 8px. 받는 마디 첫 MISS만 다음 박에 하나가 미끄러짐. 곡·노트·버튼은 멈추거나 흔들지 않음.
- 진동(웹): PERFECT `[14, 간격−14, 8]`(두 번째 톡 = 노트 + 1/16박), GREAT `[12]`, GOOD `[8]`, MISS `[25,60,25]`. 설정 끔·약·보통·강.
- 글자 표시: 한글 소리 / 한글 + 로마자 / 로마자 / 끔, 뜻 켬·끔, 3번 이어 맞히면 소리 줄 35% → 0%(MISS면 100%). 일시정지 칩 「가 · A」.

## 알려진 한계
- 임시 반주·임시 목소리: 진짜 곡(Suno)·스템·목소리(음성 합성 허락 뒤 → 원어민) 전. 목소리는 모음 공명 합성이라 사람 목소리와 거리가 멂. 한국어 가사 줄은 소리 없이 화면 글자 + 글로켄 가락.

- 판 1만. 길게 누르기(おいしいーーっ)·오른쪽 박 노트의 실제 자료 없음(코드는 오른쪽 노트 그리기·판정까지만, 길게 누르기는 없음).
- 예습·복습 웹툰, 프롤로그, 무대 사건(あ가 렌즈에서 목도리로), 눈 토끼 모래 개그, 하나 GREAT 표정(02 그림)은 아직 없음.
